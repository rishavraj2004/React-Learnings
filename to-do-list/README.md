# 📝 React To-Do List

A simple and responsive To-Do List application built with React. This app allows users to manage daily tasks efficiently by adding, completing, and deleting tasks.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Responsive design
- ⚡ Fast and lightweight React application

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/react-todo-list.git
```

2. Navigate to the project directory:

```bash
cd react-todo-list
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit:

```bash
http://localhost:5173
```

## 📖 Usage

- Enter a task in the input field.
- Click **Add** to create a new task.
- Click a task to mark it as completed.
- Use the delete button to remove tasks.
